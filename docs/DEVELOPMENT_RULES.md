# 開発ルール（本リポジトリ）

本リポジトリは **ドキュメント専用**（AWS AI-DLC Workflows 2.0 の二次整理）である。

## 優先順位

1. 本ファイル
2. リポジトリルートの方針（README / SOURCES）

## 言語

- ユーザー向け文書・コミットメッセージ本文: **日本語**
- Conventional Commits の `type`/`scope` は英語可
- ソース上の識別子・引用コマンドは英語のままでよい

## ブランチ

- 変更は `feature/*` ブランチで行う
- `master` へのマージ・リモート push は **ユーザーの明示承認後のみ**
- force-push / 履歴改ざんは禁止

## 公開時の情報保護（必須）

次をコミットに含めない:

- 個人のホームパス（`/Users/...`、`~/Documents/...` 等の個人特定可能な絶対パス）
- 他案件名・顧客名・個人名
- 認証情報・トークン・秘密鍵
- 社内専用 URL や内部ホスト名

コミット前に privacy-check（または同等のスキャン）を実施する。

## 正確性

- 数値・仕様は `awslabs/aidlc-workflows` の `main` ブランチの一次情報と突合する
  （2026-09-01 以前は `v2` ブランチ。`v2` は上流で削除済み）
- **突合の対象に `dist/` を含めない。** 2.8.x で `dist/` は上流リポジトリから削除され、
  `.gitignore` 済みのローカル生成物になった。clone しても存在しない。
  ハーネス数など従来 `dist/` 直下で数えていた指標は **`harness/` 直下**で数える
- **版を固定するときは、タグかコミット SHA のどちらかで固定する。**
  実装バージョンと最新タグは一致しないことがある（2026-09-09 時点: 実装 2.8.1 / 最新タグ `v2.8.0`）。
  - **タグを使う場合は `git ls-remote --tags origin` で実在を確認してから書く**
    （存在しないタグを指す手順書を作らないため）
  - **未リリースの実装版を調べる場合はコミット SHA で固定してよい**
    （タグが無い版をタグで固定しようとすると、調査対象より古いツリーを指すことになる）
  - **どちらで固定したかを明記する。** リリース資産が要る手順はタグ、
    ソースの照合は SHA、と用途で使い分ける
- 推測は「要一次確認」と明記する
- 本ノートは公式文書ではない旨を README / SOURCES で維持する

## レビュー

- 公開・マージ前は可能な範囲で複数 AI レビューを実施する
- 利用不能な AI は「未実施（理由）」と正直に記録する
